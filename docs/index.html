SystemBar

A tidy, transparent menu bar for macOS. Collapse the clutter, reveal what you need, and see every icon — even hidden Control Center items.

Download View Source ☕ Support

Free & open source · macOS 14+ · Screen Recording kept opt-in

🧹

One-click collapse

Hide the icons you don't need; reveal them with a click or ⌃⌥⌘B. Auto-collapses again after a delay.

🪟

Show All Icons

A floating, notch-safe panel listing every status item — hidden and visible — with their real images.

🔒

Privacy-first

Collapse needs no permissions at all. Screen Recording is strictly opt-in, only for the panel's icon capture.

⚡

Native & light

Pure Swift 6 / AppKit, zero dependencies. Tiny, fast, and signed so permissions persist across updates.

Install

brew install --cask systembar

…or grab the latest release and drag it to Applications.
